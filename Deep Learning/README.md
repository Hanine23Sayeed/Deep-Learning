This repository contains two basic Deep Learning projects designed for learning and practice. 
The first project focuses on a Convolutional Neural Network (CNN) for image-based tasks, demonstrating how convolution, 
pooling, and fully connected layers work together for feature extraction and classification. The second project implements
a Neural Network (ANN) for understanding core concepts such as forward propagation, loss functions, and backpropagation.
Together, these projects provide a solid foundation for understanding fundamental deep learning models and workflows
